# Threats to validity — paragraph flow

Collected rather than scattered, so a reader can weigh them together. Each is a
concrete confound with a named consequence, not a hedge.

- P1 opens: what would have to be true for each conclusion to be wrong.
- P2 the split is temporal, not random. The consequence, and the arm that would
  settle it.
- P3 the crop changes two things at once. The consequence, and the arm that
  would settle it.
- P4 the families do not read the same cameras, so one row is not an ablation
  of the same input as the others.
- P5 sample size: how many frames the unseen numbers rest on. Distinguish the
  effects far larger than noise from the ones that are not, by name.
- P6 attribution measures the size of a difference a stream makes, which is not
  causal importance for the task. Say what would be.
- P7 one policy family's numbers are pending at the time of writing, and which
  statements therefore do not yet cover it.
- P8 none of this is an on-robot result. Say what on-robot trials would settle
  and what they would not.
- (revised 2026-09-25) the "still pending" paragraph becomes the third family's
  own caveat: one pass over the data, a low-rank adapter, three cameras, and no
  sampler floor measured -- so its row answers "what does this budget buy", not
  "how does this family compare at convergence".
