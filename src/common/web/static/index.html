Datasets

    Recordings

      Select a recording to play its sensor view.

      Collect

      Live view and session control arrive with the next change set. Until then, start a session with tool/collect_dataset.py.

      Sensors

      Assigning devices to stream names arrives with a later change set. Until then, use tool/test_sensor_rates.py --assign.

      New dataset

      A dataset comes into being when the first episode is recorded into it, so this checks the name and hands you the command that starts the session. Starting it from here arrives with the Collect tab.
